# State

The console writes config. The gateway reads the published snapshot. Usage is a second store. Both sides use the same id for a provider, a route, and the usage of an attempt.

An id from [state.NewID](../../internal/state/id.go) is 128 random bits, hex encoded, unique among its type, and not drawn from a recycle pool. A display name is not the id. The id does not change when the object is updated.

## Files

[state.ResolvePaths](../../internal/state/paths.go) chooses both locations.

| Store | Path | Writer | Reader |
| --- | --- | --- | --- |
| Config | `AIGATE_CONFIG` when it is set, otherwise `aigate/config.json` under the platform per-user config directory | Console, through [Store.Update](../../internal/state/store.go) | Gateway and console, through [Store.Current](../../internal/state/store.go) |
| Usage | `usage/` in the directory that contains the config file | Gateway attempt loop, append only | Console `GET /usage` |

`{UserConfigDir}/aigate/config.json` and `{UserConfigDir}/aigate/usage/` are the default pair. When `AIGATE_CONFIG` is `D:\cfg\gate.json`, usage is `D:\cfg\usage\` and the default file is not read or written. The usage lines are `usage/attempts.jsonl`.

The config file is JSON. It holds listeners, the share flag, providers, routes, groups, plugins, gateway tokens, and console users. Notes for a connected coding agent are not in this document. They are `agents/<id>.json` beside the config file. See [agent wiring](agent-wiring.md). A provider stores a display name, one protocol, and one or more upstream keys for that protocol. `credential` remains the first key. `credentials` is the full list. Optional [ModelInfo](../../internal/state/config.go) for a listed model carries display name, kind, hidden, context, reasoning, whether it accepts images, and its own reasoning levels. `reasoningEfforts` is the level list. A missing field means the levels were not read; an explicit `[]` means the model has no level selector. The [codec](../../internal/state/modelinfo.go) also accepts `reasoning_efforts`, `reasoningEffort`, `reasoning_effort`, and `levels`, and writes `reasoningEfforts`. A provider key seat may also set `maxConcurrent`, `maxRPM`, `queueSlots`, and `queueWaitMS`; those values are non-negative, and zero means no cap for the first two and the process default for the last two. A gateway token may store a model allow-list. `spendLimit`, when set above zero, is a dollar cap, and `spendPeriod` is `today`, `7d`, `30d`, or `all`. A zero or absent cap does not limit spending. An empty period with a positive limit means 30 days. A negative limit is rejected. A user stores a password salt, a password hash, and session hashes. A usage write does not rewrite it. Directories are created at mode `0700` and the files at mode `0600` when the platform honors those bits. The file is not encrypted. Encryption at rest is open; see [state design](../design/state.md).

Empty listen fields are stored as empty. They are not filled with `127.0.0.1:3425` or `127.0.0.1:8081`. `share` false does not rewrite a non-loopback gateway address; that listener stays closed until share is true.

A route field `eligible` that is absent from the JSON uses only `upstream_unavailable` at attempt time. A present empty array stays empty and is written back as `[]`. [Route.EligibleOrDefault](../../internal/state/config.go) is that distinction. A route's `routing` is the strategy that orders its key seats: absent is `smart`, or `order`, `rotate`, `usage`, `pace`, `weight`, `free`, `fast`, `drain` ([routes.Known](../../internal/routes/routes.go)). `cheap` and `expiring` are rejected on a route because one provider's keys share one price and one quota family. `weights` gives each provider member's weight for `weight`; an id outside the member list or a negative weight is rejected. [state.Validate](../../internal/state/validate.go) rejects a dangling provider id, a provider with no key, an unknown class, an unknown routing id, a base URL [security.CheckBaseURL](../../internal/security/security.go) does not allow, and two listeners that bind the same host and port. A route lists provider ids in attempt order for `order`, and as the candidate pool every other strategy reorders.

A [Group](../../internal/state/config.go) has an id, an ordered `members` list, an optional `routing`, optional `weights`, and the same `eligible` presence rule as a route. It may also set `levels`, the reasoning levels offered for the whole group, and `reasoningMap`, which rewrites a client level to the level a member sends. A member is `providerId/model` or another group, either bare or as `group/<id>`. A member may add `:high` to fix one level or `:low+high` to limit its levels; `off` is stored as `none`. A provider/model member must name a model the provider lists; the level suffix is not part of the model name. `weights` keys must be members of this group, and nested group cycles are rejected. `cheap` and `expiring` are valid on a group; an empty group strategy inherits an outer `smart`, `rotate`, `usage`, `pace`, `free`, `fast`, or `drain`, while an outer `order` or `weight` leaves it on `smart`. Group ids are unique. `noAutoGroups` turns off the implicit group made when one bare model is listed by several providers. Level resolution is [reasoning](reasoning.md).

## Failed read

[Store.Load](../../internal/state/store.go) publishes an empty config when the file is missing, and does not create the file. A successful document with an empty provider list is that empty list.

A failed read, parse, or content hash is not an empty config. A document that still contains `accounts`, `consoleCredential`, or a route `accountIds` field is the same failure: those fields are not dropped and the rest is not published. The bad file is renamed to `<file>.bad`, or `<file>.bad.<n>` when that name is taken. The last good snapshot stays in memory. The first failed load leaves [Store.Current](../../internal/state/store.go) nil: the gateway accepts no model request, and the console can still serve `GET /` and `GET /config-status`. A later process start finds no file at the config path and publishes an empty config. The bad bytes stay in the `.bad` file.

A failed hash of a new document aborts [Store.Update](../../internal/state/store.go) before the file or the snapshot changes.

## Snapshot

[Store.Update](../../internal/state/store.go) clones the current config, applies the change, validates, writes a temporary file in the same directory, and replaces the config file. The in-memory snapshot pointer swaps only after that replace. [Store.Current](../../internal/state/store.go) returns a deep copy. An attempt keeps the copy it took at the start; a later update does not change it.

The reader lock is held only while that copy is made. The file write does not hold it. Plugin hooks and a dial do not hold it.

## Usage

What this store is for, and where that job stops, is [usage](../usage.md).

An [AttemptRecord](../../internal/state/usage.go) stores `routeId`, the configured `route`, the provider id, outcome, status, start and finish, duration, and the provider's own `usage` object. `usage` is omitted when missing; it is never stored as zero. A call may also store `model`, `session`, `tokenId`/`callerKeyId`, `callerIssuerId`, `providerKeyId`, `providerAccount`, `caller`, `agent`, `protocol`, `operation`, `source`, `err`/`errType`, `tries`, `handedOn`, `rejected`, `cost`, `ttft_ms`, `first_text_ms`, `queue_ms`, `retry_ms`, `bytes_in`, and `bytes_out`. Key ids are configuration ids or key fingerprints, never a secret. `caller` is the token id for an issued token, `magpie`, `magpie-<name>`, `aigate`, or `aigate-<name>` for a local key of that form, or the first word of the client identifier for any other local key. An append fills a zero `started` or `finished` with the current UTC time before computing `ms`; an explicit `ms` is kept. An older line that lacks new fields, or that still has `accountId`, still parses; `accountId` is ignored.

`handedOn` marks a failed attempt that already produced tokens and was followed by another attempt; its tokens still count but it is not a call. A 499 with `err` equal to `the agent canceled the request` (or `errType` `agent_canceled`) is a cancellation, not a failure. A local rejection is `rejected: true`, or an empty `providerId` with `status >= 400`. `source` is empty for gateway calls, `reported` for client-reported direct calls, `probe` for probes, `mcp` for MCP tools, and `search` for search. The source decides membership in totals and token limits; see [usage](../usage.md).

When the provider usage object has token counts, the line stores `in`, `out`, `cacheRead`, `cacheWrite`, `cacheWrite1h`, and `reasoning`, including zeros. `in` does not include cache read or cache write. An OpenAI or Gemini prompt total includes cached tokens, so those are subtracted. Anthropic `input_tokens` is already the uncached input, and `cache_creation.ephemeral_1h_input_tokens` fills `cacheWrite1h`, capped at `cacheWrite`. An object that only has a total is left without these fields. Explicit counts passed by a writer win over counts parsed from `usage`; [AttemptRecord.Counts](../../internal/state/usage.go) uses the stored split, or parses `usage` when the line is older.

[usage_index.go](../../internal/state/usage_index.go) keeps parsed lines in blocks of 512. A full block is frozen; a longer file is read from the previous block end, and a replaced or shorter file is read whole. There is no on-disk `log-v1.bin` cache in this build, so the first read after process start parses the whole file. [Store.ReadUsage](../../internal/state/usage.go) returns an empty list when the file is missing. A failed read, or a complete line that does not parse, returns [ErrUsageUnknown](../../internal/state/errors.go). That error does not change config and is not a zero total. A trailing partial line with no newline is skipped by a read and does not make the file unknown; before the next append, `trimUsageTail` removes that fragment so the new line starts on its own line. A complete line is never rewritten.

[state.PeriodStart](../../internal/state/usage.go) is the inclusive start of `today`, `7d`, `30d`, or `all` in the clock's location. [state.Summarize](../../internal/state/usage.go) bounds totals, groups, and series to that window. `handedOn` rows add tokens, cost, and unpriced counts but not calls or failures; a final row counts once, and a `tries > 1` answer adds `retried`. Probe, MCP, and search rows are dropped before any total. Groups are `agents`, `models`, `providerKeys`, `accounts`, `callerKeys`, and `sessions`; the session group only holds lines with a session. `cost` and `unpriced` stay zero until a reader that has a price list fills them. The price is US dollars per million tokens, applied when the line is read, and is not written back. A line with no input and no output tokens is not priced and is not unpriced, unless it carries its own `cost`; that value is used as-is. A line with tokens and no rate adds one to `unpriced`. An explicit `cost` wins.

[TokenLimit](../../internal/state/config.go) is one gateway-token cap. It may set `usd`, `tokens`, or both. A zero or omitted amount does not cap that field. `window` is `today`, `week`, `month`, `all`, `hours`, or `days`; `since` fixes a rolling window's start. `provider` and `model` narrow the rows counted. [TokenLimit.WindowStart](../../internal/state/limits.go) and `Matches` are the shared window and scope rules used by [spendBlock](../../internal/gateway/spend.go). [UsageHide](../../internal/state/config.go) hides one provider/model's rows at or before a time from the usage page only.

A finished model call that brought a session id is also filed under that id by [Store.AppendTurn](../../internal/state/conversation.go). The file is `conversations/<sha256 of the session>.jsonl` inside the usage directory. Each line is one call. `output` is the whole reply; a stream is joined before the line is written. `input` is the last user text in that request. A call with no session id is not a line. A missing directory is an empty list. A file that cannot be parsed returns [ErrConversationUnknown](../../internal/state/errors.go), which is not an empty dialogue.

## Secret fields

Provider keys and gateway token secrets are stored in the config file. A console password is stored only as a salt and a hash from [security.HashPassword](../../internal/security/security.go). A session is stored only as [security.SecretHash](../../internal/security/security.go). API responses follow [console](console.md). Logs use [security.AccessLine](../../internal/security/security.go), which is the method, the path, and the status.

Verification is the command list in [AGENTS.md](../../AGENTS.md).
