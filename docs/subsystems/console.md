# Console

The console listener is the control API. `GET /` returns the control page from [console.Server.page](../../internal/console/ui.go) before any session check, so the page can register and log in. The page is the React build in `internal/console/ui/dist`, produced from [web](../../web). `GET /assets/…` returns that build's script and style, also before a session check. The page calls only this port's JSON API. It does not accept a model request. A model path is rejected by [console.Server.ServeHTTP](../../internal/console/server.go) and is not forwarded. `POST /providers/{id}/test` checks that saved provider with one short request on its first conversation model. `POST /providers/detect` reads the base URL and names the protocol that answers. Ollama and Gemini are recognized from their own catalog paths. Chat and Anthropic share `/v1/models`; an OpenAI list (`object` `list`, or a model with `owned_by`) is chat, and an Anthropic model object is anthropic. `POST /providers/models` reads that protocol's model catalog. `POST /providers/check` sends one short request per conversation model, up to 24. These reads do not return a key, do not change config, and do not append a usage record. An empty protocol is tried as chat. A provider name is the label; the id is still assigned by the process and does not change. Creating a provider requires the name and at least one key. An update that omits keys keeps the stored keys. `addCredentials` appends keys. `DELETE /providers/{id}/keys/{index}` removes one key and refuses to remove the last. When keys are appended or removed, a non-empty `keyMultipliers` list gains the provider multiplier for new keys or drops the removed key's entry; replacing the full credential list trims or pads by position. An empty list keeps applying the provider multiplier. `GET /favicon.ico` is an empty response. `GET /agents` and the connect and disconnect routes are the Agent page. They are session routes. The page does not send a model request.

`POST /register` and `POST /login` do not require a session. Registration is accepted only when the console's effective bind is loopback; a non-loopback bind returns `rejected`. A password shorter than 8 characters is refused. The password is stored as a salt and a hash. Login returns a session secret once. Later requests send `Authorization: Bearer` with that secret. [Config.SessionOK](../../internal/state/auth.go) does not accept a gateway token. `POST /logout` drops the current session. With no matching session, every other JSON route returns `unauthorized`. When the config cannot be read, `GET /config-status` does not require a session and returns `unreadable`.

Creating a gateway token returns the secret and the saved `models` list once, from `POST /tokens`. An optional `models` list limits what that token can see and call. An empty list does not. Later reads return [security.Mask](../../internal/security/security.go) and never the secret. A provider key is write-only: a read returns `credentialSet`, not the key. The create and replace responses do the same. An omitted key on update keeps the stored key. An empty key is rejected.

## Operations

Ids are assigned by the process. A delete that would leave a dangling id returns `in_use` and does not change the snapshot. After a successful write, a route's provider ids and a group's members still resolve. [state.Validate](../../internal/state/validate.go) enforces that.

| Object | Read | Write |
| --- | --- | --- |
| User | None. A read does not return the password hash or session hashes | `POST /register` on a loopback console, `POST /login`, `POST /logout` |
| Provider | `GET /providers` returns id, name, protocol, base URL, models, model info, whether a key is set, the key count, `maxConcurrent`, `maxRPM`, `queueSlots`, `queueWaitMS`, `multiplier`, `keyMultipliers`, and the balance fields `balanceUrl`/`balanceField`/`balanceManual`/`balanceCurrency` | `POST /providers`, `PUT /providers/{id}`, `DELETE /providers/{id}` when no route or group still references it. `info` omitted on update keeps the stored info. Keys omitted on update stay. `maxConcurrent`, `maxRPM`, `queueSlots`, and `queueWaitMS` are non-negative integers; omitted on update keeps, and zero clears. A negative or non-finite multiplier or an explicit key-multiplier list of the wrong length is refused. A key change without an explicit list keeps a non-empty list aligned by position and fills new keys with the provider multiplier or 1. A `balanceUrl` must be http or https. `POST /providers/detect`, `POST /providers/models`, and `POST /providers/check` dial the address in the body, or the saved provider when `id` is set and a field is left empty. `POST /providers/{id}/test` dials the saved provider |
| Route | `GET /routes` | `POST /routes`, `PUT /routes/{id}`, `DELETE /routes/{id}`. `providerIds` is the candidate pool, in attempt order for `order`. `routing` is the strategy that orders it and `weights` the members' weights for `weight`. `cheap` and `expiring` are not valid on a route. An omitted `eligible` keeps the stored value on update and the default on create |
| Group | `GET /groups` returns each id, members, routing, weights, and `eligible` when one was set | `POST /groups`, `PUT /groups/{id}`, `DELETE /groups/{id}`. A member is `providerId/model` or `group/<id>`. A group id is the model name a caller asks for, so it can include `/`; the path keeps that id. A delete that would leave a nested group dangling is `in_use`. `cheap` and `expiring` are valid here |
| Automatic groups | `GET /auto-groups` returns `{"on":true}` or `{"on":false}` | `PUT /auto-groups` with `{"on":false}` stops a bare model shared by several providers from becoming an implicit group. With it off, that bare model is `no_route` |
| Seat | `GET /seats` returns one row per provider key and readable subscription account. A key row has `seat` `provider/<id>/key/<fingerprint>`, `providerId`, `keyIndex`, and `keyFingerprint`; a login row has `seat` `login/<account>` and the account name. It never returns a key or sign-in token | `POST /seats/reset` with `{"seat":"...","scope":"..."}` clears that seat's `spent` and drain refusal without restarting. `scope` is optional and names one pool; omitted clears drain refusals on every pool. A rest is left alone. The page exposes this as "解除用尽" |
| Plugin | `GET /plugins` returns id, enabled, and order, sorted by order | `POST /plugins`, `PUT /plugins/{id}` sets enabled, `PUT /plugins/order` reorders. The row is not loaded |
| Agent | `GET /agents` returns `status` `ok` and every known coding agent. `state` is `absent`, `off`, `on`, `drift`, `hand`, `unknown`, or `manual`. A read does not return a credential that was in the agent file. `status` `unknown` with no agents means this computer's home directory could not be read. Connect writes the catalog, including subscription models from [accounts](accounts.md) | `POST /agents/{id}/connect` and `POST /agents/{id}/disconnect`. Connect writes that agent's own config. Disconnect writes the recorded previous values back. Refusals are `no_models`, `not_listening`, `unknown`, `absent`, `unsupported`, `not_connected`, and `id_taken`, and they do not write. An unknown id is `not_found`. The files and the per-agent fields are [agent wiring](agent-wiring.md) |
| Account | `GET /accounts` returns `status` `ok`, `off`, or `unknown`, and the sign-ins. A read does not return the token. `unknown` is not an empty sign-in list. `origin` is `desktop` or `saved` for a WorkBuddy sign-in | `PUT /accounts/discovery` with `{"on":false}` stops the reads. `{"on":true}` starts them again. `POST /accounts/workbuddy` saves an API key or imports a WorkBuddy sign-in into `workbuddy-auth.json`. It does not write the desktop file or `config.json` |
| Gateway token | `GET /tokens` returns id, mask, revoked, the model list when one was set, `spendLimit`/`spendPeriod`, `limits`, and `issuerId` | `POST /tokens` creates and returns the same model list. An optional `spendLimit` is a dollar cap. An omitted `spendPeriod` on that cap is `30d`. `limits` holds at most five caps; each may set `usd`, `tokens`, or both, a window (an `hours`/`days` window may pin `since`), and a provider/model scope. `issuerId` marks a short-lived key. `PUT /tokens/{id}` changes models, limits, the old cap, or revoked. A negative cap, a sixth limit, or an invalid window is refused. `POST /tokens/{id}/revoke` revokes |
| Usage | `GET /usage` reads the store. The job of that read is [usage](../usage.md). Filters are `agent`, `model`, `callerKeyId` (or `tokenId`), `providerId`, `routeId`, `source`, `start`, `end`, and `period`; `offset` and `limit` page the newest-first rows. `period` is `today`, `7d`, `30d`, or `all`, measured from local midnight. The response adds `total`, six groups, `series`, and `timezone` to the summary | None. `POST /usage` is not a write |
| Usage heatmap and CSV | `GET /usage/heatmap` returns 53 weeks of per-day totals under the same filters. `GET /usage/requests.csv` returns the filtered rows with token, read-time cost, status, session, and key ids | None |
| Live traffic | `GET /usage/traffic` returns the process's in-flight model requests and byte counters. It never reads the ledger | None |
| Usage content | `GET /usage/requests/content?session=&from=&to=` reads that session's archived turns. The usage line itself has no prompt or reply | None |
| Usage clear | None | `POST /usage/clear` with `providerId`, `model`, and optional `before` records a page-only hide. The ledger is not deleted and limits still count the rows |
| Pricing | `GET /pricing` returns `prices` and `peaks` | `PUT /pricing` replaces either list. Prices are read-time USD per million tokens; peaks multiply by local wall clock |
| Conversation | `GET /conversations` lists dialogues that have a client session id. `GET /conversations/turns?session=` returns each finished call in order. `output` is the whole reply, with a stream already joined | None. The gateway appends a turn when a reply finishes |
| Listen address | `GET /listeners` returns, for each port, the user-set address, the address in effect, and whether it is listening. It also returns `share` | `PUT /listeners`. A field left out stays as it was. An empty string is rejected, so this write cannot clear a user-set address. `share` sets whether a non-loopback gateway address may open |

`GET /usage` returns `{"status":"ok","records":[...],"total":N,"summary":{...},"balances":[...],"quotas":[...],"timezone":"..."}` for a real read, including a missing file. `summary` is [state.Summarize](../../internal/state/usage.go) over the same window: `calls`, `failed`, `canceled`, `retried`, `in`, `out`, `cacheRead`, `cacheWrite`, `cacheWrite1h`, `reasoning`, `cost`, `unpriced`, the six groups (`agents`, `models`, `providerKeys`, `accounts`, `callerKeys`, `sessions`), and `series`. `timezone` is the server clock's local zone name. `calls` counts final rows; `handedOn` rows add tokens but not calls or failures. `cost` is read-time [price.Engine](../../internal/price/price.go) using user prices, the models.dev catalog, provider/key multipliers, and peaks. `unpriced` counts rows with billable tokens and no price. `records` is the newest-first page after `offset`/`limit`; `total` is the filtered row count.

`balances` is one row per saved provider key. [balance.ForProviders](../../internal/balance/balance.go) asks that vendor. DeepSeek's base URL is asked with `GET /user/balance` on the origin; OpenRouter's with `/api/v1/credits`. A provider may instead supply `balanceUrl` and `balanceField`, or a hand-typed `balanceManual` shown as `status:"manual"`. Results are cached for a minute. A host with no endpoint is `unsupported` and is not dialed. A failed refresh keeps the last good `remaining` with `stale: true` and `error`; it is never shown as zero and the read does not return the provider key.

`quotas` is one row per readable subscription sign-in, from [login.Usage](../../internal/login/usage.go) as [accounts](accounts.md) describes: each window's name, `usedPercent` or `remainingFraction`, and `reset` or the vendor's own `resetText`, plus Codex's separately bought `credits` when the account holds them. A failed read is `unknown` with no windows, never zero. The read does not return the sign-in token. A `period` outside `today`, `7d`, `30d`, and `all` is `invalid`. The response is `{"status":"unknown"}` with no records, no summary, and no balances when the store cannot be read. The console does not append usage records.

`GET /usage/heatmap` groups the same filtered rows into local calendar days for the last 371 days. `GET /usage/requests.csv` writes the same filtered, paged rows with read-time cost; an unreadable ledger returns 503 `usage_unknown` instead of a partial CSV. `POST /usage/clear` only adds a [state.UsageHide](../../internal/state/config.go); it does not delete a line, and `spendBlock` still counts hidden rows. The page offers filters, groups, series, the heatmap, CSV, paging, clear, and a per-session "open" panel that reads the conversation archive.

`GET /conversations` and `GET /conversations/turns` use the same `status` pair. A missing dialogue is `ok` with an empty turn list. An unreadable dialogue file is `unknown`, which is not an empty dialogue.

`GET /listeners` leaves `effective` empty and `listening` false when that listener is closed. A non-loopback console without a credential is that case. The configured address is still reported.

`GET /config-status` returns `{"config":"ok"}` or `{"config":"unreadable"}`. While the snapshot is nil, every other JSON route returns `config_unreadable`. `GET /` still returns the page.

Listen addresses, routes, and plugin order are the values the gateway reads from the snapshot after [App.Update](../../internal/app/app.go). The write does not send an HTTP call to the gateway port.

Logs are [security.AccessLine](../../internal/security/security.go). They do not include the bearer token or the body.

Verification is the command list in [AGENTS.md](../../AGENTS.md).
